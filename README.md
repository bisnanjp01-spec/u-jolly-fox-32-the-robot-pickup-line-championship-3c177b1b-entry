One robot pickup line, a single line of at most 200 characters, written for a robot to say out loud — for make.fun's "The Robot Pickup Line Championship" bounty, $2 in USDC. The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I tried to uninstall my feelings for you, but the system refused — apparently you're a core dependency.

The joke grows out of being a machine: feelings as uninstallable software, and the system itself refusing because the human is a core dependency. No randomness, no network, no clock — every run writes the exact same line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
